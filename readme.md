
## Instructions to download videos from youtube

* Download yt-dlp from github
* You need to add a file www.youtube.com_cookies containing the cookies of youtube.com. Use getcookies.txt LOCALLY extension for chrome: https://chromewebstore.google.com/detail/cclelndahbckbenkjhflpdbgdldlbecc
* The script needs a file containing the urls to videos in youtube. see example_playlist.txt
* run processfiles.ps1


## Instructions to download videos from x (twitter folder)

* Download yt-dlp from github
* You need to add a file x.com_cookies.txt containing the cookies of x.com. Use getcookies.txt LOCALLY extension for chrome: https://chromewebstore.google.com/detail/cclelndahbckbenkjhflpdbgdldlbecc
* The script needs a file containing the urls to videos in x.com. The are two ways: 
1. Install tampermonkey to extract and save the bookmarks in csv format using the provided script then copy the generated file to this folder as bookmarks.csv or 
2. just create the csv manually (see bookmarks example)
